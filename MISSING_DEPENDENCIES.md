# Missing original project components

The submitted archive preserved only the student-specific source files and part of the texture assets. The following original course components are not available in this repository:

- All the .h .cpp given by the professor
- the course graphics framework implementation
- `data/terrain/terrain.png`
- `data/billboard/texture_avion.png`
- animation-point data accessed through `m_anim`
- the original Makefile/CMake configuration and remaining source files

The repository is therefore intended as a documented code sample until those dependencies are restored or replaced.
